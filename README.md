# JamSCAN

JamSCAN is an Android mobile application for physical music collectors
that allows users to identify albums, preview tracks, and manage a
personal music collection.

## Technology Stack

### Mobile
- Flutter
- Dart
- Riverpod

### Backend
- Python
- FastAPI

### External Services
- Discogs API
- Playback API
- Visual recognition service
