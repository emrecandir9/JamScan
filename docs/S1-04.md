## Implementation details
A dedicated gallery service was added:
mobile/lib/services/gallery_import_service.dart

The service uses Flutter's existing image_picker dependency:
final image = await _picker.pickImage(
  source: ImageSource.gallery,
  requestFullMetadata: false,
);

Three result states are supported:
selected
cancelled
failed

The existing capture screen was extended rather than replaced:
mobile/lib/screens/camera_capture_screen.dart

The screen now receives both:
CameraCaptureService
GalleryImportService

Both image sources use the same image-path state and preview workflow.
A testable image-preview builder was also introduced. In production,
Image.file is still used normally, while widget tests can inject a lightweight
preview widget. This avoids depending on real filesystem image decoding during
the test suite while still verifying that the selected image path reaches the
preview correctly.
The S1-04 test file is:
mobile/test/gallery_import_screen_test.dart
