# S1-03: Camera capture

## Scope

Capture an album cover using the Android camera and display a preview.

- Request camera permission when the capture button is pressed.
- Handle cancellation, denied permission, permanently denied permission,
  and capture errors.
- Offer access to app settings when permission is permanently denied.
- Preserve the previous preview when a retake is cancelled.
- Prevent concurrent capture requests.
- Recover pending captures after Android terminates the app process.

Photos remain in the application cache. Gallery selection, recognition,
and permanent storage are outside this task.

## Dependencies

- image_picker: ^1.2.3
- permission_handler: 12.0.1

permission_handler is pinned to 12.0.1 to retain compatibility with the
project's existing Android build configuration. Version 13.0.2 required
compile SDK 37.
