## Local development readiness

The app can be tested using the APK and Android Studio emulator. For everyday
source development, follow [SETUP.md](SETUP.md) to install Flutter 3.47.5 and
Python 3.12 and make their commands available in the terminal. Validation on
Emre's Mac used a temporary Flutter SDK and an existing backend virtual
environment; normal `flutter`, `dart`, and `python3.12` commands were not on
PATH at the last check. Docker is optional locally and was verified in CI.

One non-blocking backend test warning reports deprecated `httpx` use by the
Starlette test client. The test passes; revisit the test dependency when
updating the backend libraries.
